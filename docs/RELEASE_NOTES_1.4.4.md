# Veyra 1.4.4beta

本地内测版，基于 1.4.3，未发布 GitHub 正式版本。

本轮测试包补充（2026-09-21）：

- 输出帧率可选择不限制、沿用显示器或自定义，默认不限制。XeSS 的提供方呈现路径暂不支持该自定义限制，不通过压低输入帧率冒充实现。
- 字幕默认保留设置字号，双行不再自动缩小；全屏新增锁定，锁定时鼠标活动不弹出控制条。
- 修正设置面板布局、滚动重绘和采集启动节奏问题；撤回未经验证的 XeSS 时间提示，保留生成路径的修正。
- NR 保留三个真实模型风格及命名预设，没有新增“033 模型风格”。时间域防闪烁默认关闭。
- 防闪烁修正保护区、羽化、零残差衰减和时间异常处理；复用 GPU 邻域数据，降低该阶段开销。
- 修正呈现时间统计的重复采样，区分进入与返回 Present 的媒体时间偏差；这些数据不是屏幕到人眼延迟。

已知限制：本机原始 4K60、NR、防闪烁加 DLSS/XeSS 4X 的 120 秒测试约
240 次提交/秒，但原片与目标同尺寸，超分被跳过。真正 1080p→4K 超分加 NR
时，DLSS 2X 约 120，4X/6X 约 163 次提交/秒并仍有长间隔；XeSS 4X 叠加
防闪烁也有明显掉速。这些组合尚未修好，不能承诺稳定高倍率。
独立输入降噪尚未实现；防闪烁不是源画面降噪。XeSS 果冻观感没有通过
可靠生成帧的画质对照。杜比视界新增处理仍按用户要求暂缓。

- 采集卡新增独立的自动 / 有限 / 完整输入范围，以及手动 Rec.709 SDR。保留 PQ 与 HLG 输入选择。
- 色彩空间和范围按设备保存，修改立即记忆；切换格式、帧率、刷新和重连保留该设备的选择。旧配置自动兼容。
- 手动 HDR 使用 P010/P016。压缩采集继续读取码流元数据；不支持的手动组合明确报错，不静默忽略。
- 修正混色器色相分区之间的响应缺口，以及跨越红色色相零点时的错误。保持原有调节幅度；旧预设在分区交界处的表现可能变化。

新增 Elgato 4K60 Pro MK.2 专用 HDR 入口：读取驱动私有 HDR InfoFrame，
接收原生 HDR 时关闭卡内 HDR→SDR 映射；可读取原状态时退出采集恢复。
不修改其他采集卡，也不修改全局色彩公式。接口来源为 Elgato 官方与 Nitlink（MIT）。

Elgato 4K60 Pro MK.2 HDR 测试：先让 HDMI 输入 HDR，选择 P010、自动颜色、自动范围后重连。
驱动私有元数据读取失败时再尝试 Rec.2100 PQ；新日志带 capture-elgato 接口诊断。
先关闭调色和增强，与 OBS 同一画面比较。P010 本身不能证明输入是 HDR。
原生 HDR 仍按 PQ 绝对亮度输出，没有强加减红或二次色调映射。
接口及回归测试通过不等于实卡颜色验收。该设备的偏色问题仍待用户复测；
HDMI 源运行中切换 SDR/HDR 后需要重新连接采集。

本版不新增白点/峰值滑块。OBS 全局输出的 300/1400 nit 不直接等同于采集输入参数。
运行组件身份、实验功能边界及 1.4.3 已知限制保留。
